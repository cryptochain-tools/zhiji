# Contributing to Zhiji

Thank you for improving Zhiji. Please open an issue before large changes so
maintainers can confirm product and privacy boundaries.

## Development

Use the package manager declared in `package.json`, keep changes scoped, and
run the relevant package tests, type checks, and build before opening a pull
request. Do not commit credentials, personal telemetry, source maps, generated
build output, or production configuration.

## Pull requests

Describe the user-facing behavior, tests run, data/privacy impact, and any
schema or configuration changes. Keep commits reviewable and update public
documentation when an API, SDK, deployment step, or support boundary changes.

By contributing, you agree that your contribution is licensed under the license
that governs the modified path: AGPL-3.0-or-later for the platform and design
packages, and MIT for the SDK and build-plugin packages that contain their own
`LICENSE` file.
